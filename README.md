# ⚡FITNESS BUDDY - Fitness Tracker

A dark-themed full-stack fitness tracker built with Flask and vanilla JavaScript.

## Features

- 💪 **Workouts** — Log exercises with sets, reps, and weight
- 🥗 **Nutrition** — Track calories, protein, carbs, and fats
- ⚖️ **Body** — Monitor your weight over time
- 🚶 **Steps** — Log your daily step count
- 💬 **Motivational Quotes** — Random quotes to keep you going
- 🖼️ **Workout Images** — Visual categories for each tab
- 💾 **Persistent Data** — All data saved locally to JSON

## Tech Stack

- **Backend** — Python, Flask
- **Frontend** — HTML, CSS, JavaScript
- **Storage** — JSON file
